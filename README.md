# Цех78

Демонстрационный сайт премиального автосервиса в Санкт-Петербурге.

«Цех78» — вымышленный бренд (78 — код региона Санкт-Петербурга). Адрес, телефоны, отзывы и имена мастеров — демонстрационные; фотографии — стоковые с Unsplash. Проект показывает, как может выглядеть коммерческий сайт автосервиса: понятный с первого экрана, с честными ценами, работами «до/после» и записью в два клика.

## Stack

- Next.js 16 (App Router, Turbopack, статическая генерация всех страниц)
- TypeScript
- Tailwind CSS 4
- shadcn/ui на примитивах Base UI — компоненты скопированы в `components/ui` и перестилизованы
- Framer Motion (пакет `motion`, через `LazyMotion`) + View Transitions API для переходов между страницами
- React Hook Form + Zod — формы и общая схема валидации клиента и API
- NumberFlow — анимированные счётчики

## Features

- многостраничная архитектура: главная, каталог услуг, 5 страниц услуг, работы, о нас, блог (6 статей), контакты, 404;
- responsive design, mobile-first: проверено на 375, 390, 768, 1024 и 1440 px, нижняя панель «Позвонить | Записаться» с учётом safe-area;
- before/after slider: перетаскивание мышью и пальцем (вертикальный скролл не блокируется), клавиатура, `role="slider"`;
- animations: построчный заголовок hero, лёгкий параллакс, scroll-reveal со стаггером, счётчики, magnetic-кнопки, переходы между страницами — всё с `prefers-reduced-motion`;
- forms: единая форма записи (default / focus / loading / success / error), обратный звонок, калькулятор «быстрая оценка» в 3 шага с загрузкой фото (mockup);
- SEO: уникальные title/description/Open Graph для каждой страницы, генерируемые OG-картинки, `sitemap.xml`, `robots.txt`, JSON-LD (AutoRepair, BreadcrumbList, FAQPage, BlogPosting);
- accessibility: skip-link, видимый фокус, навигация с клавиатуры, aria-атрибуты у меню, аккордеона, слайдера и форм;
- mobile navigation: полноэкранное меню на Base UI Dialog (фокус-ловушка, Esc, возврат фокуса);
- фильтр работ по услуге с синхронизацией в URL (`/raboty?usluga=hodovaya`), пустое состояние и состояние ошибки загрузки фото;
- русская типографика: неразрывные пробелы после предлогов, у чисел и единиц, перед тире.


## Демо-режим и переменные окружения

| Переменная | Значение по умолчанию | Назначение |
| --- | --- | --- |
| `SITE_INDEXING` | не задана | `true` — открыть сайт для поисковиков. По умолчанию `noindex`: бренд вымышленный, а адрес — реальная улица |
| `NEXT_PUBLIC_SITE_URL` | URL деплоя Vercel | Канонический адрес для метаданных и sitemap |

Заявки обрабатывает `app/api/lead/route.ts`: данные валидируются и никуда не отправляются. Чтобы увидеть состояние ошибки, введите телефон `+7 (000) 000-00-00`.

## Что заменить на реальные материалы клиента

- `assets/photos/works/*` — пары «до/после»: сейчас это снимки разных машин, подобранные по цвету и ракурсу (см. TODO в `content/works.ts`);
- фотографии цеха, оборудования и команды; отзывы — на отзывы с Яндекс Карт и 2ГИС;
- `lib/site.ts` — адрес, телефоны, режим работы, ссылки на соцсети;
- `app/api/lead/route.ts` — подключить CRM, Telegram-бота или почту (TODO в коде);
- загрузка фото в калькуляторе оценки — сейчас превью только в браузере;
- схема проезда `components/map-mock.tsx` — при желании заменить на Яндекс Карты по ключу клиента.

## Структура

```
app/            страницы, OG-картинки, sitemap, robots, API заявок
components/     ui (shadcn/Base UI), layout, home, service, booking, motion, blog, works
content/        услуги, кейсы, статьи, отзывы, команда — всё в типизированных TS-файлах
lib/            конфиг сайта, типографика, SEO, схема заявок, генератор OG
assets/         фото (единая цветокоррекция) и шрифты для OG-картинок
```
